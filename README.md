# Personal Project Showcase App

## About the Project

The Personal Project Showcase App is a React-based application that allows users to display, search, add, and delete projects in one place.

It provides a simple and user-friendly interface for showcasing personal and development projects.

## Features

- Display a list of projects.
- Add new projects with a title and description.
- Search projects by title or description.
- Delete existing projects.
- Responsive and user-friendly interface.

## Technologies Used

- React
- JavaScript
- HTML
- CSS
- Jest
- React Testing Library

## Installation

1. Clone the repository:

   ```bash
   git clone YOUR_GITHUB_REPOSITORY_URL
   ```

2. Navigate into the project directory:

   ```bash
   cd port
   ```

3. Install the dependencies:

   ```bash
   npm install
   ```

## Running the Application

Start the development server:

```bash
npm run dev
```

Open the local URL displayed in your terminal in your browser.

## Running Tests

Run the project tests using:

```bash
npm test
```
